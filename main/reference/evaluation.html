Evaluation#

per_suggestion#

bluesky_adaptive.evaluation.per_suggestion(evaluate, fetch)[source]#

Build an evaluation function from a function of one suggestion’s data.

The evaluation function applies evaluate to each value of fetch(uid) and sets the outcome’s "_id" to its key.

Parameters:
evaluateCallable[[_TData], Mapping[str, Any]]

Returns the outcome of one suggestion’s data.

fetchCallable[[TUid], Mapping[Any, _TData]]

Returns each suggestion’s data keyed by suggestion ID, e.g. RunEventBuffer.pop.

Returns:
EvaluationFunction[TUid]

The evaluation function.

Examples

>>> from bluesky_adaptive.evaluation import per_suggestion
>>> def score(data):
...     return {"objective": 10 * data["x"]}
>>> evaluation_function = per_suggestion(score, lambda uid: {"a": {"x": 1.0}, "b": {"x": 2.0}})
>>> evaluation_function("run-uid", [])
[{'objective': 10.0, '_id': 'a'}, {'objective': 20.0, '_id': 'b'}]

Maps the evaluation function’s UID, e.g. QueueItemRuns.resolve.

Returns:

Examples

>>> from bluesky_adaptive.evaluation import per_run
>>> def evaluate_run(uid, suggestions):

[{'_id': 'a', 'run': 'run-1'}]

RunEventBuffer#

class bluesky_adaptive.evaluation.documents.RunEventBuffer[source]#

Bases: CallbackBase

Buffer the "primary" event data of acquisition runs by suggestion ID.

Subscribe with RE.subscribe(buffer) or to a remote document stream, and pass pop() to per_suggestion(). Buffers runs that record start["bluesky-adaptive"]["acquisition_order"], as default_acquire() does, pairing the n-th event with the n-th suggestion ID. Thread-safe; use one buffer per consumer.

QueueItemRuns#

class bluesky_adaptive.evaluation.queueserver.QueueItemRuns(re_manager_api, *, timeout=60.0, poll_interval=0.5, run_filter=None)[source]#

Bases: CallbackBase

Resolve Queue Server item UIDs to the UIDs of the runs they open.

bluesky-queueserver 0.0.26 and later record start["queue_server"]["queue_item_uid"] in every run. Subscribe this callback to the Queue Server’s document stream before submitting plans and pass resolve() to per_run(). It uses each item’s first run that passes run_filter and returns once that run’s stop document arrives, so read the data with a reader that waits for the run to stop, such as TiledRunPoller, or from the same stream with RunEventBuffer.

While the RE Manager reports the item queued or running, resolve() waits without a time limit. Thread-safe; use one instance per runner, since consuming an item drops the items whose runs started earlier.

Warning

Part of the experimental queueserver integration; the API may change without deprecation.

Parameters:
re_manager_apibluesky_queueserver_api.zmq.REManagerAPI | bluesky_queueserver_api.http.REManagerAPI

The RE Manager running the items.

timeoutfloat, optional

Seconds to wait for the run’s stop document once the item has finished. Default is 60.

poll_intervalfloat, optional

Seconds between RE Manager requests while waiting. Default is 0.5.

run_filterCallable[[RunStart], bool] | None, optional

Selects runs by start document, e.g. lambda start: not start.get("dark_frame"). Called on the dispatcher’s thread; its exceptions are raised from resolve().

Raises:
ValueError

If timeout is negative or poll_interval is not positive.

Examples

runs = QueueItemRuns(RM)
dispatcher = RemoteDispatcher("localhost:5578")
dispatcher.subscribe(runs)
threading.Thread(target=dispatcher.start, daemon=True).start()
evaluation_function = per_run(per_suggestion(score, TiledRunPoller(tiled_client)), runs.resolve)
agent = QueueserverAgent(RM, ..., evaluation_function=evaluation_function)

TiledRunPoller#

class bluesky_adaptive.evaluation.tiled.TiledRunPoller(client, *, poll_interval=0.5, timeout=60.0)[source]#

Bases: object

Poll Tiled for a stopped acquisition run and return its "primary" data by suggestion ID.

Pass an instance to per_suggestion(). Every call polls Tiled until the run has a stop document, so the run’s documents may reach Tiled after the acquisition plan returns, e.g. through a separate TiledWriter service. Reads runs that record start["bluesky-adaptive"]["acquisition_order"], such as from default_acquire(), pairing the n-th "primary" row with the n-th suggestion ID.

Parameters:
clientContainer

Tiled container keyed by run UID that a TiledWriter writes to, e.g. tiled.client.from_uri(...) or a CatalogOfBlueskyRuns.

poll_intervalfloat, optional

Seconds between polls. Default is 0.5.

timeoutfloat | None, optional

Seconds to wait for the run’s stop document before raising TimeoutError, or None to wait indefinitely. Default is 60.

Raises:
ValueError

If poll_interval is not positive or timeout is negative.
